# CoinWars v1.2.0

## 主な変更点

- 起動画面とタイトル画面を追加しました。「はじめから」「つづきから」を選べます。
- タイトル画面の「スコアランキング」で、このPCで終了した挑戦の最高スコアと上位10件を確認できます。
- 「セーブ一覧」で再開地点と保存日時を確認できます。戦闘ごとの記録には勝敗、戦闘前後のHP、HPの増減、コインが表示されます。
- 「リザルト一覧」でクリア・敗北・途中終了した挑戦を振り返れます。チャレンジ番号で絞り込んだり、戦闘ごとの詳細を開いたりできます。
- 起動時にGitHub Releasesの新しい正式版を確認します。更新が見つかったら、タイトル画面からインストーラーをダウンロードして更新できます。

## インストール・更新

Windows x64向けの `CoinWars-Setup-v1.2.0.exe` をダウンロードして実行してください。v1.1.1以前からの更新は今回だけ手動で行います。既存のセーブは引き継がれます。.NETランタイムは同梱されています。インストーラーはコード署名されていません。
