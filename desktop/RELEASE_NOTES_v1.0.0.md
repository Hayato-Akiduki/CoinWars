# コイン・ウォーズ ver1.0

Windows向けC#版の初回正式リリースです。

## インストール

添付の **CoinWars-Setup-v1.0.0.exe** をダウンロードして実行してください。Windows x64向けで、.NETランタイムを同梱しています。
既存のC#版から更新する場合も同じインストーラーを使用できます。セーブは `%LOCALAPPDATA%\CoinWars` に保存されます。

## 主な機能

- 16種類のキャラクターを雇用・合成し、20ラウンドを戦うオートバトル。
- 前衛・後衛、絆、装備、投資イベント。
- マウスによる購入・配置・装備とドラッグ操作。
- 小画面向けの縦スクロール・2段ショップ、文字サイズ100% / 115% / 130%。
- 売却の取り消し（他の操作でゲーム状態が変わるまで、直前の1回分）。
- ★2・★3への連鎖合成を含む購入比較。
- 一時停止、倍速、効果音・演出設定、自動保存とバックアップ復元。

## リリース前の修正・検証

- 小画面でのウィンドウのはみ出し、待機枠満杯時の購入判定を修正。
- 配置上限まで残り1枠のときに比較対象の空き枠が消える不具合を修正。
- 敵データ・戦闘補正が不正なセーブの復元判定を強化。
- 回帰チェック53項目成功。100シードの通し対戦と500パターンの購入・配置予測の照合を含みます。
- 960×640の画面でショップ表示と売却取り消しを確認済み。

## 補足

インストーラーはコード署名されていません。`SHA256SUMS.txt` は配布ファイルの整合性確認用です。
比較画面の数値は★を反映した基礎値で、装備・絆・投資の補正を含みません。
本作はマネーウォーズを参考に制作した非公式の独立したゲームです。
