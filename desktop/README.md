## 0.4.0 小画面対応・売却取り消し・合成比較

- 小さい画面やWindowsの拡大表示でも、起動サイズと最小サイズを作業領域内に収めます。
- 待機枠が満杯で合成もできない場合、購入ボタンを無効にして理由を表示。キーボード購入にも同じ判定を適用。
- ウィンドウ幅1200未満または高さ760未満では、キャラ中心の縦スクロール配置に自動切替。ショップは2段、大きな顔と購入ボタンで操作できます。
- 売却後は画面下の「売却を取り消す」で、キャラ・コイン・装備をまとめて復元。他の操作でゲーム状態が変わるまで有効な1回分の取り消しです。終了後は保持しません。
- 購入比較は★2・★3への連鎖合成と素材キャラの消費を含めて予測。比較だけでは実際のセーブを変更しません。
- 戦闘開始時はスクロールを先頭に戻します。ダイアログ表示中は背後の操作を遮断します。

検証：自動チェック47項目（100シードの対戦検証を含む）、960×640での表示・ショップ・売却取り消しを確認。

## 0.3.0 文字サイズ・キャラクター比較

- 設定の「文字サイズ」で100% / 115% / 130%を切替。次回起動にも引き継ぎ。
- 説明ダイアログはスクロール対応。省略されたラベルはマウスを重ねて全文確認。
- ショップの肖像をクリックすると、購入候補と配置中キャラの役割・HP・攻撃・速度・スキルを比較。
- 比較する配置枠を変更可能。追加・入れ替えを仮定した絆の人数と段階の増減を表示。
- 数値は★を反映した基礎値（装備・絆・投資補正を除外）。比較操作では実際の編成を変更しません。
- 購入はショップ下部・比較画面のボタン、または数字キー1～5。購入後は待機エリアへ入り、合成条件を満たすと合成。

UI検証：130%設定の保存・再起動、比較表示、スクロール、購入時の所持金減少と待機枠への追加を確認。

## 起動

- インストーラー: artifacts/CoinWars-Setup.exe
- インストールせず起動: artifacts/app/CoinWars.exe（appフォルダー全体が必要）
- Windows x64、.NET同梱、オフライン対応。
- 旧版から同じインストーラーで更新できます。
- セーブ: %LOCALAPPDATA%/CoinWars/save.json。旧C#版のセーブを引き継ぎます。
- 効果音・演出設定: 同じフォルダーのpreferences.json。
- 元のmoney.html、balance/、img/は変更していません。
- EXEのコード署名はありません。

## 画面と演出

- 青紫の立体ステージ、上部の進行ライン、左側の絆、右側の装備バッグ。
- 下部に経験値購入、待機エリア、所持金、肖像付きショップを配置。
- 16体すべてに統一したアニメ調の立ち絵。元のimg/の素材は保持。
- キャラクターのドラッグ配置。選択→配置先クリックも使用可能。
- 開戦時のシャッター・スキャン演出。
- スキル発動時のキャラクターカットインと技名。
- 攻撃移動、斬撃、雷撃、回復、シールド、ヒットスパーク、ダメージ数字。
- 行動順の予測表示、HP・スキルゲージ、倒れたキャラクターの減光。
- 合成時のランクアップ表示、戦闘終了時のMVP付きリザルト。
- 短い合成効果音。設定から消音と演出軽減が可能。
- 大画面は全体表示、小画面は縦スクロールに切り替えてキャラと操作ボタンのサイズを確保。

戦闘数値・抽選・20ラウンド構成は旧C#版から変更していません。
前衛4枠・後衛4枠の現在のゲームルールを維持しています。
本家の3Dモデルやカメラワークを完全再現したものではなく、2D立ち絵とWPF描画で
近い画面構成と演出のテンポを目指しています。

## 操作

- キャラクター: ドラッグ、または選択→移動先。
- 装備: 装備バッグから選択→味方クリック。2ラウンド後から取り外し可能。
- 1～5: 購入 / D: ショップ更新 / F: 経験値 / E: 選択キャラ売却
- Space: 戦闘開始 / P: 一時停止 / M: 効果音 / H: ヘルプ / Esc: 閉じる・選択解除
- F11: 最大化切替
- 戦闘中: ×1/×2/×4、一時停止。
- 準備とイベントは自動保存。戦闘中に終了すると戦闘直前から再開。

## 開発

.NET 10 SDK、外部NuGetパッケージ不要。
インストーラー生成にはInno Setupが必要です。

    dotnet run --project desktop/CoinWars
    dotnet run --project desktop/CoinWars.Checks -c Release
    powershell -ExecutionPolicy Bypass -File desktop/build.ps1 -Compiler "C:/path/to/ISCC.exe"

- Game.cs: ゲームルール・セーブ・UI用の戦闘イベント。
- App.cs: 画面構成・入力・戦闘進行。
- Visuals.cs: ステージ・カード・立ち絵・ドラッグ操作・基本エフェクト。
- Cinematics.cs: カットイン・開戦・行動順・技別演出・リザルト。
- GameAudio.cs: ローカルPCM効果音。音声ファイルのダウンロードは不要。
- Assets/characters.png: 4×4のRGBAキャラクター素材シート。
- Assets/GENERATION.md: built-in image_genで使用したプロンプトと素材情報。
- units.json: 16体の基礎データ。

UI検証用の引数 --preview はアプリの隣のpreview/へ別セーブを作ります。
通常のプレイデータには影響しません。インストール先での一般利用には不要です。
