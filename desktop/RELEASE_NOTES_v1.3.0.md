# CoinWars v1.3.0

- 新しい挑戦で「やさしい」「標準」「むずかしい」を選べます。敵のHPと攻撃力が変わり、スコアは難易度別に記録されます。
- 魔導の絆を調整しました。2体でスキル効果＋20%、4体で＋50%になり、4体時の発動短縮を廃止しました。
- 編成画面で絆カードを選ぶと、現在の人数や各段階の効果を数値で確認できます。
- 終了画面にラウンド推移と最終編成を表示します。各ラウンドの戦闘レポートでは、味方ごとの与ダメージ、最初に倒れた味方、生き残った敵を確認できます。
- 同点はランキングと終了画面で同率表示になります。同じ難易度の過去最高スコアを上回ると「自己ベスト更新」と表示します。

## 更新方法

v1.2.0をお使いの場合は、タイトル画面の「ゲームの更新」から更新できます。手動で更新する場合は、Windows x64向けの `CoinWars-Setup-v1.3.0.exe` を実行してください。既存のセーブを引き継ぎます。難易度の記録がないセーブは「標準」として読み込みます。
