# CoinWars v1.1.1

## 主な変更点

- 設定からチャレンジ番号を指定できます。友人と同じバージョン・番号で始めて、到達ラウンドや残りHPを比べられます。
- チャレンジの終了画面から、同じ番号で再挑戦できます。
- 雇用直後のキャラクターの枠が金色に光ります。戦闘結果では味方のMVPと最初に倒れた味方を確認できます。
- 戦闘中に終了した場合はそのラウンドの準備画面から再開することを設定画面に明記しました。
- 同梱する.NETランタイムとインストーラーのライセンス文書を補完しました。

## インストール

Windows x64向けの `CoinWars-Setup-v1.1.1.exe` をダウンロードして実行してください。.NETランタイムは同梱されています。セーブは既存の保存先を引き継ぎます。インストーラーはコード署名されていません。
